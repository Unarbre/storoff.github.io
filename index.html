Installation

Windows

Lancez l'installeur. Windows peut afficher « Windows a protégé votre ordinateur » (l'application n'est pas signée) : cliquez sur Informations complémentaires puis Exécuter quand même.

macOS

Ouvrez le .dmg et glissez Storoff dans Applications. L'application n'étant pas signée par Apple, au premier lancement faites clic droit → Ouvrir. Si macOS indique que l'application est endommagée, exécutez dans le Terminal : xattr -cr /Applications/Storoff.app

Linux

Rendez le fichier exécutable puis lancez-le : chmod +x Storoff-0.0.2.AppImage && ./Storoff-0.0.2.AppImage

Où sont mes histoires ?

Dans le dossier Documents/Storoff. Elles ne sont jamais supprimées lors d'une mise à jour ou d'une désinstallation.
